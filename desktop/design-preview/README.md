# CheezyClash: desktop UX/UI concept

Интерактивное окружение для оценки изменений. Основной клиент не заменён. Все данные вымышлены, сеть и системные настройки не используются.

## Запуск

Из `desktop`:

```powershell
npm run preview:ux
```

Открыть http://127.0.0.1:4178. Остановка — Ctrl+C. Для другого порта можно задать `CHEEZY_UX_PORT`. Установка дополнительных пакетов не требуется. `index.html` также открывается напрямую в браузере.

## Что можно оценить

Редакция 2 возвращается к виджетам текущего клиента. Принципы и границы закреплены в [UX-REVIEW.md](UX-REVIEW.md).

- Главный виджет с фоновым графиком, круглой кнопкой, временем подключения и Proxy/TUN.
- VPN первой группы: быстрый поиск/выбор прокси, внешний IP (пример), трафик сессии.
- Единый виджет активного профиля и подписки.
- Все девять сочетаний компоновок групп и прокси.
- Подписанная навигация; Logs и About внутри настроек.
- Тёмная/светлая монохромные темы с жёлтым акцентом, пять демонстрационных сценариев.

Данные фиксированы; IP и сетевые действия имитируются без внешних запросов. Перетаскивание виджетов и проверки сервисов оставлены на будущее.

## Рендеры и проверка

Используется установленный в проекте Electron; окно скрыто, профиль данных временный, HTTP(S) блокируется. Основной процесс приложения и ядро не запускаются.

```powershell
npm run render:ux -- --check
```

Чтобы дополнительно получить текущий интерфейс из исходников с существующими тестовыми данными:

```powershell
npm run build
npm run render:ux -- --check --baseline
```

## Короткая оценка сценариев

1. Из состояния «Отключено» подключиться и определить выбранный режим и сервер.
2. Выбрать Frankfurt для основной группы, затем Helsinki для мессенджеров. Убедиться, что основной маршрут не изменился.
3. Найти соединения Discord и определить, какое правило и сервер использованы.
4. В сценарии «Ошибка TUN» найти восстановление службы и альтернативу через Proxy.
5. В сценарии «Профиль обновлён» определить, применилось ли обновление, и применить его.
6. В сценарии «Первый запуск» добавить пример подписки и подключиться.

Фиксировать время до правильного действия, ошибочные переходы, понимание Proxy/TUN и уверенность в текущем статусе. Сначала сравнить сценарии на 1024 × 800 и 1440 × 980. Это план оценки; пользовательское исследование ещё не проводилось.
