# Desktop UX: согласованное направление, редакция 2

Предыдущая концепция дашборда отклонена. Основа — существующий desktop-клиент.

## Зафиксированные принципы

1. Монохромная палитра с жёлтым акцентом; без цветных статусов и цветового кодирования стран.
2. Интерфейс из карточек-виджетов. Возможность настройки состава и перемещения — будущая задача. В этом макете фиксированная сетка.
3. График остаётся фоном главного виджета. Он приглушён для читаемости текста.
4. Существующие варианты компоновки прокси сохраняются: группы — список / сетка / карусель; серверы — список / крупная сетка / мелкая сетка. В макете работают все девять сочетаний.

## Главная

**Подключение:** большая круглая кнопка с доступным именем и подписью действия, состояние подключения, длительность сессии, Proxy/TUN, скорости поверх фонового графика. При смене режима активного соединения показывается подтверждение переподключения.

**VPN:** выбранный прокси именно первой группы (в демонстрационном профиле — «Основная»). Выбор в других группах не меняет этот виджет. Быстрый список находится в верхнем слое браузера, позиционируется относительно кнопки, раскрывается вверх или вниз по доступному месту, ограничен размерами окна и имеет собственную прокрутку. Положение пересчитывается при прокрутке и изменении окна. Есть поиск, выбранный пункт, закрытие Escape/кликом снаружи, возврат фокуса после выбора.

Здесь же размещены внешний IP и скачанный/отправленный трафик за сессию. IP 203.0.113.42 — демонстрационный, запросов к публичным API нет. Для будущей реализации рассматриваются ip-api.com, ipinfo.io, api.ipquery.io, api.seeip.org, ident.me. Их протоколы, лимиты, авторизация и условия ещё не проверены; провайдер пока не выбран. Реальная проверка должна идти через активный маршрут, показывать время результата, обрабатывать таймаут и отсутствие сети, не выдавать старый IP после смены маршрута. Статусы популярных сервисов отмечены как будущая возможность и не имитируют успешные проверки.

**Подписка:** активный профиль, срок действия, общий лимит, использованный и оставшийся трафик в одной карточке. Трафик подписки не смешивается с трафиком текущей сессии.

## Навигация

Главная, Прокси, Соединения, Профили, Настройки — с текстовыми названиями. Журнал (Logs) и О приложении (About) находятся внутри настроек. Свои правила доступны из главного виджета, как в текущем клиенте.

## Проверка и границы

Изолированный макет; рабочие React-компоненты не заменены. Проверены взаимодействия виджетов, поиск и выбор прокси первой группы, независимость групп, положение выпадающего окна при прокрутке/resize, все девять компоновок, навигация в Logs/About, ширины 1440/1024/800/390 px. Рендеры просмотрены. Время, скорости, IP, лимиты и служебные операции — демонстрационные. Настоящие API, VPN, автоматический счётчик времени, перенос карточек и проверки доступности сервисов ещё не реализованы.
